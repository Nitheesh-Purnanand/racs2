# RACS2 — Retrieval-Augmented Coverless Semantic Steganography

Research reimplementation of **AgentSemSteCom** (Meng et al., *Secure Intellicise Wireless
Network: Agentic AI for Coverless Semantic Steganography Communication*, IEEE TCCN 12, 2026),
plus **RACS**, which replaces exactly one stage of it — reference acquisition — with
deterministic retrieval instead of diffusion generation, so the two can be compared under
identical conditions.

```
Secret Xs ─► Kpub (LLM) + Xfeat (structure) ─► Xref ─► EDICT hide + token perturbation
          ─► Xstego ─► SwinJSCC semantic codec ─► AWGN ─► decoder
          ─► EDICT inversion + inverse perturbation ─► recovered secret [─► CodeFormer]
```

* **Baseline (AgentSemSteCom)**: `Xref` is generated by PicX-Real + ControlNet, token-seeded.
* **RACS (Phases 17+)**: `Xref` is retrieved from a CLIP/FAISS-indexed corpus and selected by
  the digital token. Everything downstream is imported unchanged, so any measured difference
  is attributable to the reference stage.

The hard protocol invariant is `Xref_tx == Xref_rx`: the transmitter and receiver must
reproduce the same reference bit-for-bit, or recovery fails.

## Run the baseline

Every command prints its result tables to the terminal.

```powershell
cd D:\racs2

# See the latest results immediately, computing nothing
.venv\Scripts\python.exe scripts\run_baseline.py --show

# Re-check every gate against the existing artifacts (minutes)
.venv\Scripts\python.exe scripts\run_baseline.py --verify-only --yes

# One image end to end, saving secret | reference | stego | correct | wrong | no_token
.venv\Scripts\python.exe scripts\baseline_example.py --mode paper --image-id eva_facial_0000 --class facial --snr 10

# The whole baseline, Phases 1-16, paper components, assets checked first (hours)
.venv\Scripts\python.exe scripts\run_baseline.py --mode paper --yes

# Just the two expensive phases
.venv\Scripts\python.exe scripts\run_baseline.py --from-phase 15 --to-phase 16 --yes
```

Outputs land in `experiments/results/`:

| File | What it holds |
| :-- | :-- |
| `final_baseline_report.md` / `.json` | the whole baseline in one place (also printed) |
| `final_baseline_table.csv` | recovery quality per class and SNR |
| `baseline_table.json` | frozen Phase 15 evaluation table |
| `baseline_security.json` | correct / wrong / no_token recovery |
| `baseline_steganalysis.json` | XuNet detector accuracy |
| `baseline_run_log.json` | what ran, in what order, how long |

## Paper components in use

| Stage | Component |
| :-- | :-- |
| `Kpub` | Qwen2.5-0.5B-Instruct (greedy) over a BLIP perception caption |
| `Xfeat` | OneFormer ADE20K Swin-L (common) · OpenPose body+face (facial) · none (style) |
| reference | PicX-Real + SD v1.5 ControlNet (seg / openpose), token-seeded noise |
| hiding | EDICT on SD v1.5, mixing 0.93, η 0.05, with IPAdapter-plus at weight 1 |
| channel | SwinJSCC (C = 64) analog JSCC + seeded complex AWGN at 5/10/15/20 dB |
| enhancement | CodeFormer, fidelity 0.5, facial class only |

Weights are fetched by `scripts\fetch_paper_assets.py` and pinned by SHA-256 in
`models/PAPER_ASSETS.json`. Where this environment forced a difference from the paper — 256 px
instead of 512, 20 EDICT steps instead of 50, SwinJSCC C = 64 instead of C = 48, no MDJCM
digital branch — it is recorded in `docs/DEVIATIONS.md`. **No entry, no claim.**

## Environment

RTX 3050 Laptop, 6 GB VRAM, Windows. The venv is at `.venv`; HuggingFace/torch caches are
redirected to `D:\racs2\cache` by `common/paths.py`. `common/hf_lowmem.py` installs a
read-only safetensors mmap shim that must be imported **before** `diffusers`/`transformers`;
without it large checkpoint loads blow the Windows paging file. Several components are kept
off the GPU on purpose (CodeFormer, the IPAdapter image encoder) — see `docs/DEVIATIONS.md`.
