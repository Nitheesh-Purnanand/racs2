# RACS2 — Retrieval-Augmented Coverless Semantic Steganography

**A Generative AI project.** It hides a secret image inside a diffusion-generated stego image
and recovers it with the right key. Diffusion models (Stable Diffusion v1.5, EDICT exact
inversion, ControlNet, IP-Adapter), an LLM (Qwen2.5) that writes the public prompt from a BLIP
caption, and a generative face restorer (CodeFormer) all run inside the pipeline. On top of
that it adds a **retrieval-augmented** reference stage (CLIP + FAISS) and an exact-recovery
crypto layer.

| GenAI building block | Where it is used |
| :-- | :-- |
| Latent diffusion (SD v1.5 / PicX-Real) | Reference generation (baseline), stego synthesis |
| Diffusion inversion (EDICT) | Exactly invertible hiding and recovery |
| Conditional control (ControlNet, IP-Adapter) | Structure- and reference-guided generation |
| LLM (Qwen2.5-0.5B-Instruct) + vision captioner (BLIP) | Public key `Kpub` as a text prompt |
| Multimodal embeddings (CLIP ViT-B/32) + FAISS | Retrieval-augmented reference acquisition (RACS) |
| Generative restoration (CodeFormer) | Face enhancement after recovery |

Interview revision notes: [`docs/INTERVIEW_PREP.md`](docs/INTERVIEW_PREP.md).

Research reimplementation of **AgentSemSteCom** (Meng et al., *Secure Intellicise Wireless
Network: Agentic AI for Coverless Semantic Steganography Communication*, IEEE TCCN 12, 2026),
plus **RACS**, which replaces exactly one stage of it — reference acquisition — with
deterministic retrieval instead of diffusion generation, so the two can be compared under
identical conditions.

```
Secret Xs ─► Kpub (LLM) + Xfeat (structure) ─► Xref ─► EDICT hide + token perturbation
          ─► Xstego ─► SwinJSCC semantic codec ─► AWGN ─► decoder
          ─► EDICT inversion + inverse perturbation ─► recovered secret [─► CodeFormer]
```

* **Baseline (AgentSemSteCom)**: `Xref` is generated by PicX-Real + ControlNet, token-seeded.
* **RACS (Phases 17+)**: `Xref` is retrieved from a CLIP/FAISS-indexed corpus and selected by
  the digital token. Everything downstream is imported unchanged, so any measured difference
  is attributable to the reference stage.

The hard protocol invariant is `Xref_tx == Xref_rx`: the transmitter and receiver must
reproduce the same reference bit-for-bit, or recovery fails.

Scripts and the app add `src/` to `sys.path` themselves, so every command below runs
unchanged from the repo root.

## Setup

```powershell
python -m venv .venv
.venv\Scripts\pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe scripts\fetch_paper_assets.py      # model weights, SHA-256 pinned
```

Python 3.10 and an NVIDIA GPU with at least 6 GB are expected. Datasets and weights are not
in git (see `.gitignore`); the fetch and build scripts recreate them.

## Run the baseline

Every command prints its result tables to the terminal.

```powershell
cd D:\racs2

# See the latest results immediately, computing nothing
.venv\Scripts\python.exe scripts\run_baseline.py --show

# Re-check every gate against the existing artifacts (minutes)
.venv\Scripts\python.exe scripts\run_baseline.py --verify-only --yes

# One image end to end, saving secret | reference | stego | correct | wrong | no_token
.venv\Scripts\python.exe scripts\baseline_example.py --mode paper --image-id eva_facial_0000 --class facial --snr 10

# The whole baseline, Phases 1-16, paper components, assets checked first (hours)
.venv\Scripts\python.exe scripts\run_baseline.py --mode paper --yes

# Just the two expensive phases
.venv\Scripts\python.exe scripts\run_baseline.py --from-phase 15 --to-phase 16 --yes
```

## Paper components in use

| Stage | Component |
| :-- | :-- |
| `Kpub` | Qwen2.5-0.5B-Instruct (greedy) over a BLIP perception caption |
| `Xfeat` | OneFormer ADE20K Swin-L (common) · OpenPose body+face (facial) · none (style) |
| reference | PicX-Real + SD v1.5 ControlNet (seg / openpose), token-seeded noise |
| hiding | EDICT on SD v1.5, mixing 0.93, η 0.05, with IPAdapter-plus at weight 1 |
| channel | SwinJSCC (C = 64) analog JSCC + seeded complex AWGN at 5/10/15/20 dB |
| enhancement | CodeFormer, fidelity 0.5, facial class only |

Weights are fetched by `scripts\fetch_paper_assets.py` and pinned by SHA-256 in
`models/PAPER_ASSETS.json`. Where this environment forced a difference from the paper — 256 px
instead of 512, 20 EDICT steps instead of 50, SwinJSCC C = 64 instead of C = 48, no MDJCM
digital branch — it is recorded in `docs/DEVIATIONS.md`. **No entry, no claim.**

## Environment

RTX 3050 Laptop, 6 GB VRAM, Windows. The venv is at `.venv`; HuggingFace/torch caches are
redirected to `<repo>/cache` by `src/common/paths.py`. `src/common/hf_lowmem.py` installs a
read-only safetensors mmap shim that must be imported **before** `diffusers`/`transformers`;
without it large checkpoint loads blow the Windows paging file. Several components are kept
off the GPU on purpose (CodeFormer, the IPAdapter image encoder) — see `docs/DEVIATIONS.md`.

## Phone app (send / receive a secret image)

```powershell
.venv\Scripts\python.exe app\server.py          # prints http://<laptop-ip>:8000
.venv\Scripts\python.exe app\server.py --selftest data\secret_images\test_001.png
```

Open the printed address on two phones on the same Wi-Fi as the laptop (allow Python through
Windows Firewall when asked). **Sender**: upload a secret image -> download the stego PNG and
note the 8-digit key. Send the PNG **as a file/document** (photo mode recompresses it and strips
the public description), and share the key separately. **Receiver**: upload the PNG + key ->
recovered secret. A wrong key returns noise. The laptop does all the compute (6 GB GPU);
works at 512 px with the photo's aspect ratio kept (edge-padded to a square, cropped back on receive); hide ~30 s, plus ~20 s for the public description. `--size 256` is faster but blurrier.

**Default mode is `hybrid`**: EDICT (strength 0.5) blends the secret toward the RACS-retrieved reference for a paper-style stego look, then the encrypted original file goes into that stego's LSBs, so recovery is still byte-exact. `--mode lossless` (below) skips the diffusion look. Lossless mode (`app/lossless.py`): the secret file is encrypted with the key
(PBKDF2 + SHAKE-256 stream + HMAC-SHA256) and hidden in the 2 LSBs of a RACS-retrieved cover
(CLIP Top-10 + token pick), so the receiver gets a **byte-identical** copy and a wrong key is
rejected. No model runs on the receive side. `--mode diffusion` keeps the paper's EDICT pipeline
(approximate recovery).

### Hosting

```powershell
$env:PORT = "8000"; $env:HOST = "0.0.0.0"; $env:RACS_MAX_UPLOAD_MB = "20"
.venv\Scripts\python.exe app\server.py --mode hybrid
```

`HOST`/`PORT` (or `--host`/`--port`) set the bind address. Uploads above `RACS_MAX_UPLOAD_MB`
are refused with HTTP 413. The server is a plain `http.server` with no TLS or login, so put it
behind a reverse proxy (nginx, Caddy, Cloudflare Tunnel) that terminates HTTPS before exposing
it publicly. `--mode lossless` needs no GPU and is the cheapest mode to host.
