RACS2 Overview (GenAI project) RACS2 is a retrieval-augmented GenAI research project built on AgentSemSteCom, a coverless semantic steganography system. It replaces expensive diffusion-based reference image generation with deterministic retrieval: an LLM-generated semantic key and structural features are encoded with CLIP, matched against a FAISS-indexed image database, reranked by semantic and structural similarity, and one candidate is selected using a digital token. The rest of the pipeline, including EDICT exact diffusion inversion, token perturbation, and semantic communication over AWGN channels, remains unchanged for a controlled comparison. The goal is to reduce latency and VRAM while preserving image quality, security, and robustness.

Resume bullet Built a retrieval-augmented GenAI pipeline for coverless semantic steganography, replacing 50-step diffusion reference generation with CLIP + FAISS retrieval and token-controlled selection, while preserving EDICT-based hiding and recovery for a controlled baseline comparison. Implemented the foundation and baseline through Phases 1-16: Stable Diffusion VAE, SD v1.5 generation benchmarking, COCO retrieval corpus, CLIP embeddings, a reproducible evaluation harness with role-tagged splits and PSNR/SSIM/LPIPS metrics, the full AgentSemSteCom baseline (EDICT hiding/recovery, AWGN, semantic codec), and a frozen security/steganalysis baseline (correct-versus-wrong-token gap 4.34 dB, XuNet test accuracy 0.4875).
